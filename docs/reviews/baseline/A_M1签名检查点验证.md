# M1 签名检查点设计与验收边界

检查点格式domain/count/head/signature，签名对RFC8785规范字节进行Ed25519签名，校验端仅公钥。私钥不进入账本或导出；调用方保管并把检查点放在账本之外。每日自动签发和密钥管理命令尚未实现。

依赖显式声明为pyproject可选ledger_crypto；SDK锁环境已包含cryptography，当前contracts测试需SDK或安装此extra的环境，原core锁尚不含签名依赖，不能宣称当前全测试仅core即可运行。

专项contracts79项通过，包括合法签名、错误公钥、长度/链头/域/签名篡改和截断。认证检查点不能证明数据语义正确，也不抵御同时控制密钥和数据的管理员。

状态机、脱敏、快照、恢复与性能仍待实现；M1保持进行中。
