# M1-A2/A3 存储与独立校验验证

SQLite事件存储使用WAL、FULL、外键、BEGIN IMMEDIATE序列化链头分配；追加返回前commit，历史UPDATE/DELETE触发器拒绝。10并发写者共1000条无丢失、序号连续、哈希链正确；幂等内容冲突拒绝。

导出JSONL独占创建，避免覆盖既有导出；独立校验不导入写入端哈希函数，独立使用RFC8785和SHA256。100个位置逐一篡改全被检出；重排和重复键被拒绝；截断需传入可信长度/链头才能检出。导出返回的链头本身不等于可信签名检查点。

70项contracts测试通过。未完成：生产领域状态机、写前脱敏、快照完整性、签名检查点、进程崩溃恢复、性能及真实执行入口接线。当前存储仅接受调用者已脱敏的数据，不向业务提供任意原始参数写入能力。不得据此声称自包含账本全部验收通过。
