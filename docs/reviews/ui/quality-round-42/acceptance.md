# 第四十二轮：审批等待与执行结果收敛

依据 PRD v2.7 F4、F5：人工批准只表示审批决定，工具结果以执行端事件为准。此前结果事件清空待审批 ID 后，页面仍显示“正在等待此审批”，容易将已结束等待误认为尚未处理。

本轮把等待状态与关联运行分开：待审批时允许返回执行详情并重新进入同一审批；收到匹配工具结果或轮次结束后撤下等待提示，改为“已离开审批等待状态”，保留“查看关联运行详情”。不以此提示宣称成功执行。切换其他运行或新建任务时清除旧关联，避免返回错误运行。

定向浏览器用例验证往返、精确运行/审批绑定、处理后状态、关联运行返回、完成输出与深链接。最终 npm run verify 通过：类型、ESLint、Stylelint、契约、40文件157项单测、构建、预算、81项浏览器和1项生产性能测试。生产压缩入口 JS 157.4/260KB，CSS 12.6/40KB，字体145.4/600KB。后端8000端口仍不可用。
