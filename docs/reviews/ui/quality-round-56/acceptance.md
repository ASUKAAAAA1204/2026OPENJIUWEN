# 第五十六轮：证据、断言、导出与回放综合审计

核对PRD v2.7意图/结果分离、§7.2字段与§6.10回放要求：判定与参数展示决策身份、Gate、执行策略、理由、耗时、策略/白名单和改写摘要；事件时间线按追加序号展示意图、审批与结果，不把Gate批准当执行成功。证据视图保留正文、引用、模型/参数、时间、内容哈希和服务端链状态，正文缺失不推断事件未发生。断言独立列表、来源与定位、关联决策、缺决策高危标记及未知验证结论均有前端入口。导出核验运行绑定、审计ID、文件指纹、JSONL行及下载内容。回放绑定原顺序及每项证据引用，不执行工具，不把总复现一致率称为仅规则回放一致率。

发现并修复回放前提与结果校验不一致：前者仅判断证据正文和规则引用，遗漏内容指纹与证据引用；后者遗漏规则快照。现在两者共用hasReplayPrerequisites：证据正文、引用、合法SHA256指纹必备，经过Gate的记录还需规则快照；NONE不强制规则快照。缺材料只接受不可复现，并保留在总分母内。证据适配器同时补齐哈希格式、含时区时间与非空证据ID校验。修正一份旧浏览器fixture的任意文本哈希为合法格式的合成值，没有放宽测试或冒充真实证据。
