# 第二十四轮：生产性能基线

## 复现

在 ui 执行 `npm run build` 后执行 `npm run test:performance`；完整 `npm run verify` 已在构建、浏览器回归后追加性能门禁。性能测试使用独立5274端口运行生产预览，由测试进程直接启动和关闭服务器，禁止复用已有服务器，并检查页面没有 Vite 开发客户端。浏览器缓存禁用。

## 指标和限制

四档1440/1024/390/320，每档单次观察；DOMContentLoaded <1500ms、观察到的首次交互前LCP <2500ms、打开运行记录导航 <200ms、CLS <0.05、单个长任务 <100ms、观察到的事件时长 <200ms。导航耗时包含 Playwright 操作与断言开销；事件时长受浏览器16ms记录门槛限制，0只表示未观察到超过记录门槛的事件，不表示零延迟。观察器不支持时拒绝测量。

报告保存浏览器版本、时间、缓存条件、阈值及每档原始值，不用单次样本冒充p75/p95、真实用户INP或稳定性统计。测试使用本机桌面Chromium、回环网络、无CPU与网络限速，业务服务不可用状态；不包含真实认证、模型推理、接口延迟、设备实测或最终全部页面性能。

## 证据

performance.json 与 production-{1440,1024,390,320}.png 由性能门禁生成；四档截图已逐张检查，无关键内容遮挡。Windows 外部预览子进程关闭挂起已通过测试进程内管理服务器修复，定向测试成功退出。最终 npm run verify 成功退出：147项单元测试、62项浏览器测试、1项独立生产性能测试（四档）均通过。现阶段P01保留未完成，完整交付评分仍为30/100；完整性能报告还需要覆盖其余页面及真实服务主要操作。
