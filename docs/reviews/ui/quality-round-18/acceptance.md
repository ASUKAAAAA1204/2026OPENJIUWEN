# 第十八轮前端验收记录

2026-11-19。范围：设置中的策略版本查看、差异、切换与回滚前端。HTTP 业务响应均为合成样例，接口契约仍为草案。

## 操作行为

- 已发布配置只读；启用与回滚均切换版本指针，不改写历史版本内容。
- 完整配置可展开查看，逐字段显示规则和其他配置差异。非 ASK 超时标明不适用。
- 切换前同时核对管理员角色、服务权限、生效版本与目录修订；提交原因和确认项必填。
- 每次写入先获取当前会话，提交 CSRF、幂等请求标识、当前与目标版本及哈希。
- 成功回执核对请求、修订变化、版本指针、历史内容和审计绑定；服务声明的哈希不冒充本地完整性验证。
- 提交期间锁定配置来源与账号操作。冲突或结果未知时禁止重复提交，必须刷新核对状态。
- 只读账号可以比较配置，不能提交切换；权限矛盾和快照不一致时拒绝操作。
