# 第十七轮前端验收记录

2026-11-19。范围：账本运行创建与生命周期前端；所有 HTTP 业务响应均为合成样例。

## 操作行为

- 授权目录、可用框架和 Skill 版本从 run-context 读取，不允许输入任意执行路径。
- 稳定 task_id 创建去重，响应绑定配置修订、业务身份与请求标识；重复任务不重复开账。
- resume 保持同 run_id，段号精确 +1；已关闭运行只读，不能 resume。
- 生命周期操作带当前修订、状态和段号，先核验会话，再发送 CSRF/幂等标识。
- 状态不一致、409、未知结果时停止重复提交；可刷新重新取权限。创建未知结果可以按原任务标识查询。
- 新建任务清空旧业务身份；运行详情深链接刷新后仍重新读取服务端状态。
