# 第四十一轮：运行执行流前端适配

用户确认允许前端起草执行流契约后，本轮实现 `POST /api/v27/runs/{run_id}/execute` 的可替换 SSE 适配器。详见 `docs/api/v27-execution-stream-frontend-contract.md`。后端路由、Agent 调度和真实流重放尚未实现，测试均使用合成事件。

## 已实现与验证

- 运行详情单独启动，服务端从登记任务取正文；启动体不允许客户端覆盖任务内容或工具参数。
- 会话令牌、幂等请求 ID、Last-Event-ID、seq/turn/run/segment 校验，重连使用同一请求标识。
- 脱敏 Agent 输出、工具意图/Gate、审批请求、结果事件和轮次结束状态分开呈现。
- ASK 定位运行 ID 与审批 ID 同时匹配的审批，保留原运行详情及流式请求；批准后返回原详情续读。
- 执行期间接入全局离开保护，生命周期面板禁止并行关闭或恢复；启动面板按需加载。
- 四项执行流单测、两项执行流浏览器测试通过，含同请求续读、重复事件过滤、ASK 参数/修订绑定，以及短流断开时最多三次重连。审批返回保留原运行深链接。
- `execution-{1440,1024,390,320}.png` 与 `approval-handoff-{1440,1024,390,320}.png` 八张截图已逐张人工查看，无页面溢出或按钮遮挡。

## 性能与边界

首次全量回归的 156 项单测和 81 项浏览器通过，但独立生产性能门禁在 1440px 出现 115ms 长任务，独立复跑为107ms，超过100ms阈值。改为运行执行面板按需加载后重新构建，独立性能门禁通过。阈值未修改；最终全量重跑结果另记。

后端8000端口不可用。页面输出不证明真实工具执行、意图先写、审批安全、框架接入或账本持久化；真实服务联调和最终全流程恢复仍缺，完整交付评分保持30/100。
