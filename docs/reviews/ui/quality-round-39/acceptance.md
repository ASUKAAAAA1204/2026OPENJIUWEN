# 第三十九轮前端验收

## 范围

本轮补齐工作台写操作等待回执时的离开保护。运行详情、审批、债务、版本评估管理、策略切换/回滚和本机登录/退出状态均能汇总到工作台。处理中点击主导航、新建任务、受保护链接或浏览器返回时，保留当前工作区并提示对应操作正在等待；响应完成后恢复导航。成功登录/退出会先清除保护状态，再按既有流程刷新页面。

设置页在会话或策略写入期间锁定配置来源和分类切换，避免卸载请求中的组件。版本评估管理维持提交期间的既有表单锁定。
