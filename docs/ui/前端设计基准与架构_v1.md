# TemisGuard 前端设计与首版结构

基准：常见 Agent 工作台的信息结构；视觉参考本地「众生行记」素材。日期：2026-11-18。

布局采用左导航、顶部项目与运行状态、中央任务与工具执行流、右侧决策检查器。总览和检查分层，不将全部管理能力塞进同一屏。首版搭建结构与交互样例，数据明确标注为演示，不接真实执行、审批或持久化。

配色：纯白 #FFFFFF；克莱因蓝 #002FA7 用于主按钮、选中与焦点；中性高级灰采用 #F5F5F5 / #E5E5E5 / #8A8A8A / #666666 / #191919。#8A8A8A不作为小字号正文默认色。风险语义保留红、琥珀与绿，不能只靠颜色传达状态。

众生行记的应用边界：衬线主标题、克制留白、细线分区、编号与关联标注；操作信息使用清晰无衬线，参数使用等宽体。禁止用大面积光效、装饰字或微小字号妨碍审计阅读。不照搬人物、宗教图像或无法验证的黄金比例规律。

组件：WorkbenchShell、TaskWorkspace、DecisionInspector。左导航切换工作区，中央包含框架选择、任务输入、演示时间线、工具选择；右侧展示所选工具的Gate、参数和证据。新任务按钮清空输入并聚焦；提交只生成本地演示记录，提示不执行真实工具。

桌面三栏：导航208px、中央自适应、检查器320px；1100px以下导航缩窄，900px以下检查器下移，640px以下单列。交互目标至少36px，键盘焦点可见，状态必须有文字。

旧版ARS页面保留为LegacyStudio，通过 ?view=legacy 访问，旧链接带scenario/drawer/gate参数时兼容旧视图。新默认入口为工作台。旧接口与组件不在本次重写。

首版验收：类型检查与构建通过；导航切换、选择工具、创建演示记录和新任务重置可用；无真实审批和执行宣称；纯白/高级灰/克莱因蓝统一引用token。后续再接真实run、审批、债务及八项读数。

2026-11-19 信息结构更新：主导航固定为工作台、运行记录、人工审批、证据与债务、版本评估。工作台负责发起任务与检查工具决策；运行记录负责会话历史检索；人工审批负责待处理决策；证据与债务负责证据缺口与消解记录；版本评估负责统一口径的运行读数和版本比较。策略表、白名单与工具、框架接入、角色权限放在独立设置入口，避免配置与评估混杂。
