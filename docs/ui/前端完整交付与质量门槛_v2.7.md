## 迭代顺序

1. 交互基座：导航、信息层级、设计token、克制动效、状态反馈、键盘与窄屏。
2. 数据基座与运行闭环：核对真实接口，独立v2.7类型，统一请求状态与错误，运行/决策/证据/导出/回放。
3. 控制闭环：审批、权限、超时和过期状态，拒绝默认安全，禁止仅前端伪造成功。
4. 债务闭环：依赖传播、分类消解和历史证据；同一运行可追溯。
5. 管理闭环：八项读数、聚合、版本对比、发布闸与整改报价、设置和身份。
6. 全面验收：真实契约联调、关键流程E2E、无障碍、性能、全尺寸截图与人工检查。每次较大修改后执行截图验收。

后端缺少接口时，先完成明确标注的类型化演示适配器与同契约服务适配器，不将演示当成真实联调通过，不修改PRD降低交付范围。

## 视觉与动效规范

纯白承载内容，高级灰组织层级，克莱因蓝表示当前选择与主要行动。琥珀仅提示待审批/风险，绿仅表示确认成功，红表示拒绝/错误；不以装饰色代替语义。避免全屏大面积渐变和持续闪动。
