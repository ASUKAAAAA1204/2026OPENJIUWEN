# v2.7 运行列表前端契约草案

状态（2026-11-26 更新）：后端已实现 `GET /api/v27/runs?q=&framework=&state=&cursor=` 与运行详情。`?runs=api` 或列表来源选择器启用真实服务适配，默认会话演示保持独立。

返回 `{source:'ledger',items:RunSummary[],next_cursor:string|null}`。精确字段见 `ui/src/components/workbench/runs.ts`：id/title/framework/source、空tools数组、state、segment、started_at/completed_at、parent_run_id/child_run_ids、decision_count。列表不得伪造工具预览，详情通过运行标识访问audit接口。

state为open/closed/degraded；段号至少1；closed必须有不早于开始的结束时间，未结束运行结束时间为null。父子ID不得指向自身或同时互相重复。服务端还须验证全图委派深度不超过3、无循环；前端单页只能发现本地直接矛盾，不能替代完整图校验。

分页游标不透明，固定同一查询条件与授权范围。加载更多沿用已经提交的条件，不使用尚未提交的输入。重复运行或重复游标拒绝追加；下一页错误保留已加载项目并要求重新查询。权限失败不得回退演示，401/403/404均给出明确原因；12秒超时，重查/卸载取消旧请求。

服务端负责只返回账号可见运行并稳定分页。委派入口仅传递运行ID，关联详情必须再次授权；真实运行无法切换成本地预览或返回演示任务。前端现已提供运行创建、生命周期状态、关闭及中断恢复操作入口，对应接口与原子约束见 `docs/api/v27-lifecycle-frontend-contract.md`。运行创建/resume/关闭与父子关系已由平台测试覆盖，前端联调仍需另行验证。

已验：生命周期与重复/关系校验、分页追加、父子入口渲染、真实详情403不回退、四档截图与严重/关键axe检查；这些合成验证不代表真实授权隔离通过。

## 关联详情与深链接补充

真实运行详情显示父子委派入口；关联详情每次通过audit接口重新读取，不借用已有列表当作权限证明。URL hash仅保存run与framework，刷新后恢复真实服务详情，浏览器后退/前进恢复对应运行。URL不携带任务标题、参数、凭据或证据内容。未知/空ID或非法框架链接拒绝恢复。运行ID本身仍可能是内部标识，分享链接应遵守项目访问范围。

单快照拒绝父子自指、重复子ID或父ID同时列为子ID；全图无环、深度<=3与隐藏关联资源的访问隔离仍需服务端核验。

## 第三十五轮：列表刷新恢复

运行记录地址支持run_source=api/preview、run_framework（三个已支持框架）与run_state=open/closed/degraded。只在用户提交查询时保存已应用的框架与状态，未提交的表单修改不覆盖地址。未知值恢复全部条件。来源切换恢复对应来源，不复用其它来源结果。

刷新恢复来源及白名单条件后重新查询首屏，服务端重新授权；搜索文字、返回项目、分页游标和凭据不写URL或本地存储。详情及板块往返仍使用会话内保留的查询快照，返回列表重新写入已应用条件。此轮不实现任意旧历史条目的条件同步或搜索文本刷新恢复，不代表完整I04完成。

第三十六轮补充：列表激活期间监听popstate，来源按历史地址恢复；同一服务列表的框架/生命周期与已应用条件不同，则清空搜索文字并重新查询首屏，不借旧结果表示新条件。失活时移除监听，避免隐藏列表处理其它板块的历史事件。来源切换不在恢复过程中覆盖历史中的筛选参数。相同白名单条件的历史项仍复用当前会话快照，不恢复搜索文字或旧游标；服务权限仍须在查询与详情端点裁决。

第三十七轮分页权限撤回：所有列表请求禁用HTTP缓存；分页请求返回401/403时立即清空全部已加载项目、下一页游标及历史游标集合，停止展示原授权范围数据。普通503/网络失败仍保留原快照并要求重新查询。重新查询从首屏开始，不沿用失效游标。处理响应前先核对请求版本，已取消的旧分页401/403不能清空新查询结果。这仅验证前端接收权限响应后的清理，不证明服务端实际隔离正确。
