# v2.7 运行详情前端接口草案

状态：前端适配已实现，后端尚未实现或确认本接口；禁止据此宣称真实联调通过。既有scripts/serve_api.py只提供旧版ARS/plan/gate，不能复用旧版分数作为v2.7八项读数。

建议端点：GET /api/v27/runs/{encodeURIComponent(run_id)}/audit。同源凭据，返回JSON；前端12秒超时，切换运行/来源或离开页面取消旧请求。请求失败清空旧数据，不自动回退演示。

类型定义：ui/src/components/workbench/auditSource.ts 的AuditSnapshot和audit.ts的DecisionRecord。source必须为ledger，run_id必须匹配请求，运行state为open/closed/degraded，segment为正整数。parent_run_id可空，child_run_ids为字符串数组；decisions中的decision_id不可重复且run_id必须一致。Gate与Exec枚举独立校验，耗时非负；结果证据为空时evidence=null，存在时evidence_ref必须匹配evidence_id。chain包括status=verified/invalid/unverified与reason。前端只展示服务端校验结果，不自行声称哈希链验证通过。

错误语义：401登录失效、403无权限、404运行或接口不存在、其他非2xx服务不可用；200但契约错误禁止展示。空decisions表示暂无决策，不表示完整率100%。不回显服务端原始错误正文，避免泄露内部信息。

回放与账本导出：后续前端适配及草案已分别建立，见 v27-export-frontend-contract.md 和 v27-replay-frontend-contract.md；仍需后端实现和真实联调。预览文件不能替代授权账本导出，服务端报告的回放结果不能替代真实执行验收。

测试证据：ui/e2e/audit-source.spec.ts使用网络拦截响应验证前端渲染与异常流程；ui/tests/auditSource.spec.ts验证契约拒绝、HTTP状态、竞态丢弃。截图quality-round-3/evidence-*来自测试响应，非真实账本数据。截图上的test-*字段用于明确样例来源。

第二十二轮关系展示边界：parent_run_id/child_run_ids 仅表示当前快照的直接邻接关系，不包含子运行状态、深度或完整委派图。前端展示当前运行段号/状态及 delegate 决策原始状态，不按列表位置推断决策与子运行绑定。后续服务需提供可授权、可验证的委派边标识和结果证据才能验收完整责任链。

第二十九轮证据缺失语义：evidence=null 仅表示当前响应未提供证据正文，不能推断意图未持久化、执行未发生或结果未产生。此时仍展示已有 evidence_ref 与 rule_snapshot_ref；无引用显示「未返回引用」，事件状态显示「此响应未提供，待核对」。运行链状态与 reason 单独展示为服务报告，不以正文是否存在覆盖服务报告，也不将报告当作浏览器独立验证。只有明确标记的 frontend_preview 才显示预览未写入/未执行。

第56轮证据格式补充：正文存在时evidence_id须非空并匹配evidence_ref；content_hash非null时须为64位小写十六进制，ts非null时须含时区且可解析。材料未提供应明确null，不能用任意文本冒充哈希或省略时区。空输入/输出摘要仍保留为空证据。测试中的合成哈希使用合法格式，并不构成真实内容或账本链验证。

第三十轮主动刷新：账本服务模式提供统一刷新按钮，GET 使用 cache:no-store，加载时禁用重复刷新，仍逐次经过服务端权限判断。刷新先清空旧快照及其子面板，成功展示新快照；失败不恢复旧数据或演示。生命周期提交、导出校验和回放期间，通过子组件忙碌事件禁用主动刷新与来源切换。生命周期成功后的自动刷新等待所有已登记操作结束，避免提前卸载正在处理回执的面板。页面离开、其他导航或关闭浏览器仍可取消客户端等待，不能撤销服务端操作；本锁定不是服务端事务或互斥权限机制。

第三十二轮页面保护：运行详情把上述忙碌状态上报工作台，阻止返回列表、新建任务、主导航/设置、当前窗口品牌/旧版链接及父子运行导航，显示可关闭的原因提示。忙碌时 popstate 保持当前运行视图，并以 replaceState 修复当前地址，不新增历史项；浏览器历史位置已改变，因此不承诺还原原历史栈。完成/失败后恢复导航。beforeunload 监听器请求浏览器标准离开确认；浏览器是否展示取决于用户激活与平台策略，不能阻止强制关闭或保证响应持久化。服务端幂等、结果查询和恢复协议仍不可省略。本保护只覆盖运行详情中的三类已登记操作，不表示所有板块都有全局事务锁。

第三十三轮详情位置：账本详情链接可携带 decision（非空、无首尾空白、最长512字符）及 view（判定与参数/事件时间线/证据与账本/回放）。仅序列化运行/框架/决策标识和视图名称，不写入搜索词、参数正文、凭据或回放结果。用户选择决策、切换视图或从断言定位时 replaceState 更新位置，不增加逐次点击历史。刷新仍重新读取授权账本；回放视图恢复不自动发起回放。决策标识不在当前非空快照时显示未找到提示，不选首条；用户可清除定位或主动选择其他决策。无效视图回到判定与参数，跨运行决策参数不恢复。筛选、审批草稿及所有板块完整刷新恢复仍未实现，不能据此视为I04完成。

第三十四轮定位一致性：已定位决策被搜索、类别或Gate筛选隐藏时保留标识，显示隐藏提示和清除筛选入口，不以筛选后的首条替代定位。主动定位异常动作会明确清除原决策定位，再展示对应筛选集合。从预览切回账本时恢复原账本链接的决策与视图，预览选择不会写入账本链接。同运行前进/后退恢复对应位置；跨运行仍重新读取权限与账本。
