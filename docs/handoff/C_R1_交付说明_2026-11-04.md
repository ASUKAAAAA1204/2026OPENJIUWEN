## 2. 运行方式

```bash
.venv/Scripts/python -m pip install -e ".[dev,api]"
.venv/Scripts/python scripts/assurance.py run --run-id r1 --outputs outputs
.venv/Scripts/python scripts/assurance.py verify-ledger outputs/r1/ledger.json
.venv/Scripts/python scripts/assurance.py serve --outputs outputs --port 8008
```

Windows 可用 `make run` / `make verify` / `make api`；实际逻辑都在 CLI。

产物：`outputs/r1/` 下 `report.json`、`ars.json`、`plan.json`、`gate.json`、`ledger.json`、
`claims.json`、`signals.json`、`measurements.json`、`governance.json`、`debts.json`；
全局 `outputs/LATEST.json`、`outputs/corpus.jsonl`、`outputs/debt-events.jsonl`。
