## 1. CH-L：L 接入 A 的读回值匹配

### 实现

`ledger/evaluator.py` 的 `resolve_all` 改为两步：

1. C 的 `_resolve_locator` 继续做位置结构、文件名、字段名、公司绑定和主位置检查
2. 通过后再调用 A 的 `resolver.resolve_bytes`，用 `source-snapshot` 原始字节核对读回值与断言值

只有两步都通过才返回 `RESOLVED`。主 locator 和全部操作数 locator 都要求通过。失败映射：

| A 的结果 | C 的 L 状态 | C 的 reason_code |
|---|---|---|
| `RESOLVED` | `RESOLVED` | null |
| `VALUE_MISMATCH` | `VALUE_MISMATCH` | `VALUE_MISMATCH` |
| `NOT_FOUND / EXPECTED_VALUE_MISSING` | `NOT_FOUND` | `MISSING_FIELD` |
| 其他 `NOT_FOUND` | `NOT_FOUND` | `NOT_FOUND` |

数值匹配沿用 A 的相对容差 `1e-6`，零不另加绝对容差。`evaluate_claim` 的复算口径未改，
R 仍由独立 verifier 负责；本轮只收回 L 的假成功分子。

### 结果

- 原 100 条样本：`line_lookup` 全部 `verified`，300 个位置全部 `RESOLVED`，L = 100/100
- 三类反例（在内存中改副本，不重封包、不改原证据）：

| 反例 | `resolve_all` 状态 | reason_code | pe locator 明细 |
|---|---|---|---|
| 期望值改为 13 | indeterminate | `VALUE_MISMATCH` | `VALUE_MISMATCH` / `numeric_relative_1e-6` |
| 删除期望值 pe | indeterminate | `MISSING_FIELD` | `NOT_FOUND` / 缺断言值 |
| 期望值改为 NaN | indeterminate | `VALUE_MISMATCH` | `VALUE_MISMATCH` / `non_finite_number` |

三类反例都不再贡献 L 的成功分子，主 locator 同样不计成功。
复现见 `tests/test_c_l_integration.py`，明细样例在 `outputs/ch-l-counterexamples.json`（未入库）。

## 2. CH-M4：支持 `assurance-rule-binding-v1`

### 实现

- `evaluator.rule_from_payload` 识别 `format = assurance-rule-binding-v1`
- 只取 `compiled_result.ir`，要求 `compilable = true`、`type = cmp`、六个算子之一
- `ir_version` 不是 `b-cmp-v1` 时返回 `None`
- `verifier._ir_from_rule` 独立实现同一封装解析，不调用 evaluator
- 规则来源写入 `provenance = assurance-rule-binding-v1`

### 结果

`fixtures/a_handoff/20261102/A_R1_20261102.zip` 内 `package-001.json`：

```bash
.venv/Scripts/python scripts/assurance.py replay outputs/r1-binding-package-001.json
```

```json
{
  "claim_id": "c-001",
  "rule_id": "b-pe-less-than-industry@1",
  "status": "verified",
  "reason_code": null,
  "operands": {"industry_pe": "20", "pe": "12"},
  "comparison": "lt",
  "predicate": true,
  "evaluator": "c-evaluator-v1",
  "replay_id": "c-replay-v1"
}
```

删除测试的最小必要证据是 `source-snapshot`、`claim-inputs`、`rule` 三件：

- 移除任一件 → `replay` 返回 `None`
- 移除无关事件 payload（`event-*`）→ 结果不变
- 输出不含时间、耗时、随机 ID

### 未做

- claim → rule 仍只读 C 的静态映射表，不现场解析自然语言
- 没有改写 A 的原始证据包
