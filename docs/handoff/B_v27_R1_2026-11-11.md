## 计算口径

| 对象 | 本轮口径 |
|---|---|
| 三类标记 | `NO_EVIDENCE`、`SOURCE_CONFLICT`、`SPEC_MISMATCH`；源不可达归缺证据，不当作源冲突 |
| 传播 | 只沿输出依赖边传播；原始等级不变，下游显示等级最低衰减到 low；缺失依赖显式报告 `UNKNOWN_DEPENDENCY` |
| 债务 | high=3、mid=2、low=1；不按 CU 成本计量；同一决策的不同标记类型分别计条；同一债务重复输入不重复开立 |
| 消解 | 追加事件并保留原始条目；缺证据补证、源冲突统一来源、参数不一致修正并重新过闸；保留消解证据引用 |
| 八项运行读数 | 声明一致率、证据完整率、复现率、回放一致率、时效有效率、标记密度、处置执行率、不确定债务 |
| 零分母 | 比率为 null，状态为不适用，不参与平均；债务直接登记加权值和条目数 |
| 缺决策断言 | 显式 `MISSING_DECISION`，high 缺证据，进入复核；保留在声明一致率分母及缺证据统计中 |
| Skill | 同一 Skill 和版本，最近 20 次已结束的有效运行，按运行等权；至少含 1 个白名单决策才算有效；至少 5 次且至少 3 个白名单决策类，否则提示样本不足 |
| 委派 | 决策按所属运行计数；父运行自身决策保留，纯编排运行不贡献样本；子债务单独列出，聚合不重复计算 |

## 验收样例

样例为合成数据。三类标记各 2 条：缺证据 high+mid=5，源冲突 mid+mid=4，参数不一致 low+low=2，合计 6 条、权重和 11。各消解一条，分别去除 high 3、mid 2、low 1，剩余 3 条、权重和 5。应保留 6 个开立事件及 3 个消解事件，并逐条列出消解证据引用。

新增测试已覆盖多标记密度不超过 100%、传播链与环、70 节点长链、5 秒时效边界、缺证据不抬高复现率、ASK/DENY/REWRITE 的实际处置、父子去重、20 次窗口及样本门槛。缺决策断言明确计入 high 债务；存在一个完整证据也不能遮住另一个缺失的必需引用；父引用和子快照对同一债务状态冲突时拒绝聚合。

## A/C/D 接入责任

白名单类及版本由 A/C 按 PRD 引用的《关键决策白名单 v1.0》提供。本轮不自行编造 11 类枚举或宣称已验证覆盖；输入标识必须能对应上游冻结的白名单版本。

- A：提供稳定的运行和决策标识、所属运行、白名单类和版本、参数与策略的比较事实、证据及时间戳、输出依赖边；不得用模型自评补成通过事实。
- C：验证事实来源与内容引用，将 B 的开立和消解事件写入只追加账本，调用独立回放并传入事实结果；负责运行结束结算、恢复、阈值复核队列和只读 API。
- D：展示八项读数、债务条目与消解引用、实际样本数和覆盖类数；零分母显示不适用，样本不足时不展示聚合读数；不得从这些结果合成旧 ARS 档位。
