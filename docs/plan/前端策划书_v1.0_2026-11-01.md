## 0. 一句话

前端不是报表页，是**发布闸的操作界面**。所有版式与交互只服务一个时刻：**ARS 47 < 70 → 阻断 → 弹出方案与报价**。

## 1. 范围与边界

### 1.1 本次交付

| 交付物 | 说明 |
| --- | --- |
| 一屏 Studio | 坐标栏、总分卡、五维、扣分项、方案表、预算档位、提升曲线 |
| 闸门交互 | 阻断弹窗、执行修复、豁免表单、放行态 |

| 组件库 | 11 个自建组件 + 一套 design tokens |

### 1.2 明确不做

- 不在前端计算任何分数、增益、CU——**所有数字由 JSON 提供**，前端只做格式化与呈现；
- 不接后端 API，不写真实数据采集；
- 不做登录、权限、多租户；
- 不做移动端适配（最低 1024px 宽，主用 1280–1440px）。

**DEMO 组合**：U1 走通 + U6 看见提升 + U5 看见拦截，合计 2 分 40 秒。

## 4. 视觉规范

### 4.1 Design tokens

| token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F4F6F9` | 页面底色（高调白，非纯白） |
| `--surface` | `rgba(255,255,255,.72)` | 半透明面板（叠加 + 12px 模糊） |
| `--hairline` | `#D5DCE5` | 1px 细线（主要边界的唯一手段） |
| `--grid` | `rgba(120,144,156,.14)` | 蓝图网格 1px 线 |
| `--ink` | `#14181D` | 主文字、分数 |
| `--ink-2` | `#5A6673` | 次要文字 |
| `--ink-3` | `#9AA3AF` | 标注、刻度、NA |
| `--blue` | `#78909C` | 科技蓝（坐标、引线、选中） |
| `--gold` | `#C2A16A` | 圣光金（≤3 处：印章、当前档标记、选中维） |
| `--danger` | `#B3261E` | D 档、阻断 |
| `--warning` | `#B26A00` | C 档、债务 |
| `--success` | `#2E7D5B` | A/B 档、放行 |

> 白底投影比深底更稳（投影仪本身偏白，深底会发灰）；对比度仍按 WCAG 校验，彩色文字一律用深色变体，不用亮色。

### 4.2 视觉母题（来自《众生行记》，只取语言不取素材）

| 母题 | 落地方式 | 用在哪 |
| --- | --- | --- |
| 蓝图线稿 | 1px `--grid` 网格 + 同心辅助圆，透明度 ≤ 0.15 | 页面底层、总分卡背后 |
| 极细衬线 | 数字与标题用衬线（Noto Serif SC / Cormorant），字重 300–400 | **只用于**总分、档位、区块标题 |
| 技术标注 | 10–11px 无衬线大写 + `letter-spacing: .18em` | 维度名、坐标、表头 |
| 引线标注 | 维度条到标签之间加 1px 折线 + 3px 圆点编号（①–⑤） | 五维区 |
| 断线边角 | 面板不做实心边框，只画 L 形角标（左上/右下各 12px） | 所有面板 |
| 刻度与坐标轴 | 页面左右边缘每 32px 一个 2px 刻度；底部一条水平轴 | 全局框架 |
| 垂直文字 | 低透明度竖排英文（`AUDIT READINESS`） | 最左侧装饰列，宽 40px |
| 印章 | 圆形细线章，内嵌档位字母 | 阻断弹窗右上角 |
| 扫描/粒子 | 加载时一条 600ms 横向扫描线；粒子默认关闭，演示可选 | 首屏 |

**三条纪律**：衬线只出现在三个位置（总分、档位、区块标题）；彩色只出现在档位与阻断两处；装饰层永远在数据层之下且不可交互。

### 4.3 字体

| 用途 | 字体 | 许可 |
| --- | --- | --- |
| 数字/标题 | Noto Serif SC（中文）、Cormorant Garamond（数字） | OFL |
| 正文/标注 | IBM Plex Sans / Inter | OFL |
| 等宽数字 | IBM Plex Mono（分数、CU、计数） | OFL |

字体本地打包（`ui/src/assets/fonts/`），不依赖 CDN，保证离线演示。

### 4.4 状态语义（三要素：图标 + 文字 + 颜色）

| 状态 | 呈现 |
| --- | --- |
| 阻断 | 红色方块图标 + 「阻断」 + `--danger` |
| 通过 | 深绿对勾 + 「通过」 + `--success` |
| 警告 | 赭黄三角 + 「警告」 + `--warning` |
| 无数据 | 灰色横线 + 「无数据」 + `--ink-3` |

不得只用颜色区分；正文对比度 ≥ 4.5:1，色块 ≥ 3:1。白底上不使用亮色，全部用深色变体。

### 4.5 数字规则

- 全部 `font-variant-numeric: tabular-nums`；
- 分数：72px 衬线（Cormorant）、字重 400、只报整数；数字与档位之间留 12px；
- 分项：主显 `9/20`（IBM Plex Mono），辅显细条，不写百分比小数点；
- CU：一位小数（`34.0` 可简写 `34`），不写 `34.00`；
- 分档：`B` 用衬线大字 + 10px 大写标签 `BAND`，中文释义用 12px 无衬线；
- 标签统一 10–11px 大写 + `letter-spacing: .18em`。

### 4.6 缺失态（必须视觉可分）

| 状态 | 画法 |
| --- | --- |
| `VALUE` | 实心填充 + 计数 |
| `NA`（分母 0） | 虚线空轨道 + 「无适用项」，不计入总分 |
| `MISSING`（未采集） | 45° 斜纹 + 「未采集」 |
| 样本不足（n<10） | 条尾 `n=6` 徽标 + 整体降饱和，总分显示 `—` |

### 5.2 关键组件约定

#### CoordBar

- props: `coord`、`docState`
- 三段必须全部可见；缺失段显示红色 `未指定`，不允许省略掩盖。
- 右侧导出按钮下载当前 `report` JSON。

#### ScoreCard

- props: `score`、`band`、`counts`、`docState`
- `docState !== 'COMPLETE'` 时分数位显示 `—`，下方一行「PARTIAL · 样本不足，不出总分」，闸门按钮同时禁用。
- 数字下方一行小字：`20 条结论 · 10 条规则 · 10 个检查`（改造后为 14 个检查）。
- 背后铺一组同心辅助圆（半径 120/160/200px，1px `--grid`）+ 左侧 32px 刻度列；档位以圆形细线章呈现（直径 44px）。

#### DimensionBars

- props: `dims`（每维 `{num, den, state, weight}`）、`clickable`
- 行高 40px；轨道 2px（不是填充块），每 5% 一个刻度；权重以 10px 标注放右侧。
- 每行左侧一个 3px 圆点 + 细引线连到维度名（编号 ①–⑤）。
- 点击 → 打开 EvidenceDrawer 并预置该维筛选；**这是"分数即筛选器"**。

#### DeductionList

- 最多 3 条；每条：一句人话 + 数字 + 动作 + 价格。
- 例：`可定位率 9/20：11 条只有文件名、没有行号 → 补定位 9 条 · 6.3 CU`
- 点击整行 → 抽屉显示对应 claim。

#### PlanTable

- 列：动作 / 数量 / 成本 CU / 预期增益 / 性价比（分/CU）
- 严格按性价比降序；只有性价比列带 3px 细线微条，其余纯文本；无斑马纹，行间 1px hairline。
- 行高 40px；表头 10px 大写标注。
- 底部合计行：`34 CU → 79 分（B 档）`，右侧小字 `含 5% 缓冲`。

#### BudgetPills

- 5 档（0 / 8 / 16 / 24 / 34 CU），切换时只改曲线高亮与预测值，不改表。

#### CostCurve

- uPlot 折线，x=累计 CU，y=ARS；点直接标注；不画平滑样条；无填充色。
- 线：1.5px `--ink`，点 4px 空心圆；阈值线 y=70 用 1px `--danger` 虚线 + `发布门槛 70`。
- 边际 <0.5 分/CU 区间画竖虚线 + `边际枯竭`；坐标轴只留底部与左侧 1px 细线，无边框。

#### GateDialog

- 宽 480–560px；白面板 `--surface` + 12px 模糊，无实心边框，只留四角 L 标。
- 阻断态：面板左缘 2px `--danger` 竖线 + 右上角圆形印章（内嵌档位 `D`）。
- 两张并排决策区（各 48%），中间 1px hairline 分隔，**不做填充卡片**。
- 左「执行修复 → +32 分」主按钮；右「豁免发布」次按钮。
- Esc / 点遮罩不关闭；关闭需二次确认；默认焦点在主按钮。
- 文案不得用「确定/取消」。

#### AckForm

- 原因码单选（`预算耗尽 / 低严重度 / 延后 / 结构性不可验`）+ 备注必填。
- 提交后：页面顶部常驻 banner「已豁免 · 原因码 BUDGET_EXHAUSTED · 2026-12-27」，闸门按钮变为「查看豁免记录」。

#### EvidenceDrawer

- 右侧抽屉 480px，`aria-modal`，focus trap。
- 顶部：维度名 + `9/20`；列表：claim 编号、一句话、状态（已定位/未定位/无法验证）。
- 单条展开：locator（`file:row:field`）、digest 前 8 位、判定状态、失败码。

### 5.3 动效与过渡规范（丝滑的来源）

#### 5.3.1 四条原则

1. **动效只表达状态变化**：入场、切换、下钻、阻断。数据本身不"呼吸"、不循环、不闪烁。
2. **一次只动一个焦点**：同一时刻只有一个区域在动，其余静止；禁止整屏同时飞入。
3. **先响应，后演出**：按下 90ms 内必须有视觉反馈；结果呈现可以慢，交互反馈不能慢。
4. **可中断**：任何入场动画被用户操作打断时立即跳到终态，不排队、不回弹。

#### 5.3.2 动效 token

| token | 值 | 用途 |
| --- | --- | --- |
| `--dur-press` | 90ms | 按下反馈 |
| `--dur-fast` | 120ms | hover、状态色切换 |
| `--dur` | 180ms | 展开、淡入淡出 |
| `--dur-slow` | 240ms | 抽屉、弹窗、排序重排 |
| `--dur-hero` | 600ms | 首屏数字生长、扫描线 |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 进入（默认） |
| `--ease-in-out` | `cubic-bezier(.4,0,.2,1)` | 位移、滑块 |
| `--ease-spring` | `cubic-bezier(.34,1.36,.64,1)` | 抽屉/弹窗，回弹幅度 ≤4% |

只允许对 `transform`、`opacity`、`filter` 做过渡；`width/height` 仅允许用 `grid-template-rows` 展开技巧，禁止逐帧改布局。

#### 5.3.3 组件级动效表

| 组件 | 触发 | 动效 | 时长 / 曲线 |
| --- | --- | --- | --- |

#### 5.3.4 首屏编排（总时长 ≤1.6s）

```text
0 ──── 200 ──── 400 ──── 600 ──── 900 ──── 1200 ─── 1600
装饰层淡入
     坐标栏
            总分数字生长
                  档位章 + 五维条
                          方案表
                                  曲线揭示
```

规则：编排只播放一次，切场景不再重播装饰层；任一点击跳过剩余编排直接到终态。

#### 5.3.5 "丝滑"的工程指标（比动效更重要）

| 指标 | 标准 | 做法 |
| --- | --- | --- |
| 按下反馈延迟 | ≤90ms | `:active` 只改 transform，不触发重算 |
| hover 反馈 | ≤120ms | 只改颜色/透明度，不触发布局 |
| 场景切换 | ≤250ms 可见变化 | 数据预加载 + 交叉淡变 |
| 滚动/拖动 | 稳定 60fps | 不做 `scroll` 监听里的计算，用 `IntersectionObserver` |
| 抽屉/弹窗 | 打开 ≤300ms | 一次 spring，不做二次回弹 |
| 图表交互 | 读数 ≤80ms | uPlot 原生 overlay，勿用 Vue 响应式逐点渲染 |
| 模糊层数量 | 同屏 ≤2 处 | `backdrop-filter` 开销大，只给抽屉与弹窗 |
| 长列表 | 200 条以内不分页 | 超过再加虚拟滚动 |

#### 5.3.6 无障碍与降级

- 尊重 `prefers-reduced-motion: reduce`：时长归零、数字直接跳到终值、扫描线与粒子不播放、印章不缩放（只淡入）；
- 低性能设备（`navigator.hardwareConcurrency ≤ 4` 或投影机 30Hz）：装饰层透明度降到 0.08，取消首屏编排，只保留 120ms 淡入；
- 动效永不阻塞点击：动画期间控件仍可操作。

#### 5.3.7 代码落点

| 文件 | 内容 |
| --- | --- |
| `styles/motion.css` | 上表 token、`prefers-reduced-motion` 覆盖、通用 transition 类 |
| `composables/useTween.ts` | 数字滚动（rAF + easeOutCubic，可中断） |
| `utils/flip.ts` | 表格排序 FLIP（记录旧 rect → 应用新序 → 反向位移 → 播放） |
| `App.vue` | 首屏编排时间线，用 `requestAnimationFrame` + 状态位，不用 CSS delay 堆叠 |

禁止引入动画库（GSAP / Framer Motion / anime.js）：本项目动效数量可控，原生 CSS + 1 个 tween 工具足够，且能保证 60fps。

## 7. 交互流程

### 7.1 主流程（演示主线）

1. 打开 `?mock=design`：坐标栏齐全，只显示 C=3/10，顶部提示「可编译率 0.30 · 建议先改规则」→ 点「继续」写入 `design_ack`（仅前端状态）；
2. 切 `?mock=pre`：总分 47 · D 档，五维条可点；
3. 点 `L 9/20` → 抽屉列出 11 条未定位 claim → 点第一条看 locator 缺失；
4. 点「发起发布」→ GateDialog 阻断（`47 < 70`）→ 左卡显示「执行修复 34 CU → 79」；
5. 点「执行修复」→ 场景切到 `post`：79 · B 档，闸门放行，曲线显示 `(0,47)→(34,79)`；
6. 回退到 `pre`，点「豁免」→ 选原因码 + 备注 → 顶部常驻豁免 banner。

### 7.2 分支流程

- **PARTIAL**：`?mock=partial` 时总分显示 `—`，五维正常显示但降饱和，闸门按钮禁用并提示「样本不足，不可发布决策」；
- **DESIGN_ONLY**：只显示 C；C 不达标只出提示条，不弹阻断框；
- **导出**：任意状态可导出当前 `report`，文件名 `ars_<skill>_<model>_<date>.json`。

## 8. 工程结构

```text

  src/
    main.ts

    api/
      types.ts

    components/           # 见 §5.1
```

约束：

- 无路由、无 Pinia；`useReport` 一个 composable 足够；
- 组件不得互相 import 私有状态，数据一律 props 下行、事件上行；
- 唯一允许的第三方运行时依赖：`uplot`、`axios`（mock 模式下 axios 不触发）。
