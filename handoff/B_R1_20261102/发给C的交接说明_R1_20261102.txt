怎么使用

1. 解压到独立目录，先看 RETURN_NOTE.txt、RETURN_MANIFEST.json、verification/RUN.txt。
2. 优先审查 interfaces/C_alignment_request.json，再看以下材料：
   interfaces/rules.json：规则快照，规则版本 b-pe-v1。
   interfaces/compiled_rules.json：编译结果，IR 版本 b-cmp-v1。
   interfaces/field_mapping.json：pe、industry_pe 的字段和来源映射。
   interfaces/claim_rule_mapping.json：待 C 确认的逐 claim 候选关联。
   cases/fixtures.json：正例、反例、边界输入、预期及 B 实际执行结果。
   cases/failures.json：四类编译失败样例。
3. 在自己的 Python 环境安装依赖。本轮已在 Python 3.14 验证：
   python -m pip install "pydantic>=2.6,<3" "pytest>=8" "python-dotenv>=1,<2" "rfc8785==0.1.4"
4. 在解压根目录执行，替换路径占位符：
   python runtime/scripts/receive_a_handoff.py --handoff "<A原交接包目录>" --output "<新的结果目录>"
   python -m pytest runtime/tests -q --basetemp outputs/pytest
   --handoff 指向包含 MANIFEST.json 和 data/ 的 A 原包根目录；--output 必须是尚不存在、位于 A 原包之外的新目录。此流程不需要 API Key。

runtime/ 是独立复现的候选快照。正式合并时按 changed_files/ 和文件摘要逐项审查；根测试和验证脚本也请 C 审查后纳入统一入口。
共享模型差异见 interfaces/shared_interface_requests.json，需由接口负责人定版，不要直接覆盖冻结的 core/schema。
